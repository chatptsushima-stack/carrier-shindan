# 風ノ残響 — Echoes of the Wind

ブラウザで動くオープンワールド・アクションRPGのプロトタイプ。
「キレイなグラフィック・自然・アクション・重厚なストーリー性」をテーマに、
外部アセット一切なし(全て手続き生成)で構築しています。

## 遊び方

ES Modules を使っているため、静的サーバー経由で開きます。

```bash
# リポジトリのルートで
python3 -m http.server 8000
# → http://localhost:8000/game/ を開く
```

(`npx http-server` などでも可。GitHub Pages にそのままデプロイ可能)

### 操作

| 入力 | 動作 |
|---|---|
| WASD | 移動 |
| マウス | 視点(クリックでポインターロック) |
| Shift | ダッシュ(スタミナ消費) |
| Space | ジャンプ |
| 左クリック | 剣攻撃(ダッシュ中は踏み込み斬り) |
| 右クリック / C | 回避ロール(無敵時間あり) |
| E | 調べる / 話す |
| ホイール | カメラズーム |

## ストーリー

百年前、「影ノ獣」に呑まれて滅んだ王国。記憶を失った旅人が草原で目を覚ます。
長老ナギに導かれ、三つの祠に預けられた「記憶の欠片」を取り戻すと、
自らが封印の騎士の最後の一人だったことを思い出す——。
北西の祭壇で破られかけた封印を、今度こそ完全に断ち切るのが旅の目的。

進行は localStorage に自動保存され、タイトルの「続きから」で再開できます。

## 技術構成

- **Three.js(同梱・CDN不要)** + UnrealBloom ポストプロセス
- **地形**: fBM値ノイズによる手続き生成。高さ関数を描画・物理・配置で共有
- **草原**: 5.2万本のインスタンシング。頂点シェーダーでプレイヤー中心に
  無限ラップし、高さマップ/地形カラーマップのテクスチャから接地と色馴染みを取得。
  風の大きなうねり+個別の揺れ
- **空**: シェーダースカイドーム(昼夜グラデーション・太陽・月・星・fBM雲)
- **昼夜サイクル**: 太陽方向に連動してライト・フォグ・露出・草の色温度が変化。
  夜は時間が速く流れる。夜はホタル、昼は鳥の群れが舞う
- **アクション**: ヒットストップ、ノックバック、回避ロール、スタミナ管理、
  敵AI(徘徊/追跡/攻撃/帰巣)、ボス第2形態
- **サウンド**: WebAudioで全て手続き生成(風・環境音楽パッド・小鳥・剣戟・咆哮)
- **自動品質調整**: 平均FPSを監視し、ブルーム→解像度→草密度の順に軽量化

## 開発メモ

- `window.__debug` にゲーム状態を公開しており、Playwright による
  E2Eテスト(会話→欠片取得→ボス→エンディングの完走確認)に使用
- ファイル構成:
  - `index.html` — UI(タイトル/HUD/ダイアログ/ナレーション)
  - `main.js` — ゲーム本体
  - `lib/` — 同梱した Three.js とポストプロセスモジュール
