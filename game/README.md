# 風ノ残響 — Echoes of the Wind

ブラウザで動くオープンワールド・アクションRPGのプロトタイプ。
「キレイなグラフィック・自然・アクション・重厚なストーリー性」をテーマに、
外部アセット一切なし(全て手続き生成)で構築しています。

## 遊び方

ES Modules を使っているため、静的サーバー経由で開きます。

```bash
# リポジトリのルートで
python3 -m http.server 8000
# → http://localhost:8000/game/ を開く
```

(`npx http-server` などでも可。GitHub Pages にそのままデプロイ可能)

### 単一HTMLとして書き出す

Three.js もゲーム本体も1ファイルに埋め込んだ配布用HTMLを作れます。
外部リクエストを一切しないので、ファイルをそのまま開くだけで遊べます。

```bash
npm install esbuild            # 初回のみ(ESBUILD 環境変数でパスを指定可)
node game/build-single.mjs     # → game/dist/kaze-no-zankyo.html
```

ポインターロックが許可されない環境(iframe内など)では、
自動的に「ドラッグで視点、その場クリックで攻撃」に切り替わります。

### 操作(PC)

| 入力 | 動作 |
|---|---|
| WASD | 移動 |
| マウス | 視点(クリックでポインターロック) |
| Shift | ダッシュ(スタミナ消費) |
| Space | ジャンプ |
| 左クリック | 攻撃(ダッシュ中は踏み込み斬り) |
| 右クリック / C | 回避ロール(無敵時間あり) |
| E | 調べる / 話す |
| Q / 1〜3 | 武器切替 |
| ホイール | カメラズーム |

### 操作(スマホ・タブレット)

タッチ端末では自動的にタッチUIに切り替わります(`?touch=1` で強制表示も可能)。

- **画面左半分をなぞる** — 触れた場所に仮想スティックが出現。倒し具合で速度が変わり、
  いっぱいまで倒すとダッシュ
- **画面をドラッグ** — 視点操作
- **右下のボタン** — 攻撃 / 回避 / 跳 / 調べる / 武器切替
- **画面タップ** — 会話・ナレーションを送る

タッチ端末では描画設定を自動的に軽くします(草の本数を削減、ブルーム無効、
影の解像度を下げる)。`?perf=high` で強制的に高品質、`?perf=low` で強制的に軽量。

## 武器

| 武器 | 入手 | 特徴 |
|---|---|---|
| 旅人の剣 | 最初から | 威力1・素早い。癖がなく振りやすい |
| 風薙の槍 | 依頼「牙を折る」の報酬 | 間合い4.3m・直線上の2体を貫く。当たる角度は狭い |
| 古の大剣 | 風見の頂の石塚から | 威力3・広い薙ぎ払い。重く、スタミナを大きく消費 |

## 敵

| 敵 | 挙動 |
|---|---|
| 草の粘塊 | 跳ねて近づく最弱の敵 |
| 影の魔物 | 爪で殴る近接型 |
| 迷イ火 | 一定の間合いを保ちながら火の玉を撃つ。横滑りして狙いを外す |
| 岩背獣 | 溜めてから直線に突進。正面で受けると大ダメージ、避けて横を叩く |
| 影ノ獣(ボス) | HP半分で第2形態へ。加速し、影の魔物を呼ぶ |

## ストーリー

百年前、「影ノ獣」に呑まれて滅んだ王国。記憶を失った旅人が草原で目を覚ます。
長老ナギに導かれ、三つの祠に預けられた「記憶の欠片」を取り戻すと、
自らが封印の騎士の最後の一人だったことを思い出す——。
北西の祭壇で破られかけた封印を、今度こそ完全に断ち切るのが旅の目的。

### サイドクエスト(狩人トキの依頼)

スポーン地点の西に狩人トキがいます。本編とは独立に進められる依頼が3つ。

1. **牙を折る** — 気の立った岩背獣を3頭退ける。報酬は「風薙の槍」
2. **風鈴の在り処** — 草原に遺された3つの風鈴を見つけて届ける。報酬は最大HP+2ハート
3. **風見の頂** — 東の独立峰に登り、騎士たちの石塚から「古の大剣」を引き抜く

進行は localStorage に自動保存され、タイトルの「続きから」で再開できます。
本編が未進行でも、依頼を受けていれば「続きから」で再開できます。

## 技術構成

- **Three.js(同梱・CDN不要)** + UnrealBloom ポストプロセス
- **地形**: fBM値ノイズによる手続き生成。高さ関数を描画・物理・配置で共有
- **草原**: 5.2万本のインスタンシング。頂点シェーダーでプレイヤー中心に
  無限ラップし、高さマップ/地形カラーマップのテクスチャから接地と色馴染みを取得。
  風の大きなうねり+個別の揺れ
- **空**: シェーダースカイドーム(昼夜グラデーション・太陽・月・星・fBM雲)
- **昼夜サイクル**: 太陽方向に連動してライト・フォグ・露出・草の色温度が変化。
  夜は時間が速く流れる。夜はホタル、昼は鳥の群れが舞う
- **アクション**: ヒットストップ、ノックバック、回避ロール、スタミナ管理、
  敵AI(徘徊/追跡/攻撃/帰巣)、ボス第2形態
- **サウンド**: WebAudioで全て手続き生成(風・環境音楽パッド・小鳥・剣戟・咆哮)
- **自動品質調整**: 平均FPSを監視し、ブルーム→解像度→草密度の順に軽量化

## 開発メモ

### ファイル構成

- `index.html` — UI(タイトル/HUD/ダイアログ/ナレーション/タッチUI)
- `main.js` — ゲーム本体
- `lib/` — 同梱した Three.js とポストプロセスモジュール
- `tests/` — Playwright による E2E テスト

### テスト

`window.__debug` にゲーム状態を公開しており、ヘッドレス Chromium から
実際に遊んで検証できます。

```bash
python3 -m http.server 8765          # 別のターミナルで起動しておく
node game/tests/quest.mjs            # 本編:会話→欠片→ボス→エンディング
node game/tests/sidequest.mjs        # 依頼3種と報酬・セーブの復元
node game/tests/combat.mjs           # 武器3種の威力/間合い/スタミナ、新しい敵の挙動
node game/tests/touch.mjs            # 仮想スティック・視点ドラッグ・各ボタン
node game/tests/scenery.mjs          # 主要ロケーションのスクリーンショット(/tmp/scene_*.png)
```

ソフトウェア描画では数FPSしか出ないため、テストは実時間ではなく
ゲーム内の状態をポーリングして待ちます(`helper.mjs` の `waitState`)。
